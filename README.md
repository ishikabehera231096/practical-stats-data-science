# Practical Statistics for Data Scientists

A hands-on collection of data science projects inspired by *Practical Statistics for Data Scientists (AI-Assisted Edition)*.

## About

This repository documents my journey through practical statistics and data science, with one applied project for each chapter of the book.

The objective is to develop practical skills in exploratory data analysis, statistical inference, predictive modelling, machine learning and generative AI using real-world datasets.

## Learning Approach

Each project includes:
- Business problem and research questions
- Dataset exploration and data quality checks
- Statistical analysis and visualizations
- Interpretation of findings
- Limitations and conclusions

## Data Sources

Datasets are sourced from public repositories, research institutions and government portals. Original dataset sources and licensing information are documented within each project.
